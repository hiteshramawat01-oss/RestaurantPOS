# Changelog

## 1.3.0

- Simpler app: no sign-in or staff users, and no Sales screen.
- Settings now has only Printer and App update.
- Find printers: searches the phone's Wi-Fi for network printers; tap one to use it.
- Tables set to AC 1–5 and Non-AC 1–8.
- Mewari Makkhan Dhaba's full menu (105 dishes) with Half / Full and Plain / Butter prices; tap a dish to choose the size.
- Bills show Mewari Makkhan Dhaba with address and phone.
- This version changes the Android app itself, so it is installed once from the APK.

## 1.2.0

- The Android app now updates itself: new versions download in the background and install the next time the app is closed (or tap "Restart now").
- Updates are checked every 30 minutes while online. Each download is verified by its SHA-256 fingerprint, and the app returns to the previous version if a new one fails to start.
- Changes to the Android app itself (for example the printer code) still need a new APK; the app says so when that happens.

## 1.1.1

- The sign-in screen shows the app version, so you can see which version is installed.

## 1.1.0

- Takeaway orders: start one from the Tables screen with "New takeaway"; any number can be open at once.
- Optional customer name on takeaway orders, printed on the kitchen slip and the bill.
- Kitchen slips for takeaway say "TAKEAWAY #order - PACK".
- Test builds can now be updated from Settings → App updates.

## 1.0.0

- First release: tables, order taking, kitchen tickets, billing, sales, menu, settings, backup.
